# Living models

No system models have been recorded yet. Create them from actual reading and probes; do not pre-fill expected findings. Read [the protocol](../PROTOCOL.md) for prediction, observation and score rules.

| File to create | Information it carries |
|---|---|
| `map.md` | Entry points, packages, verbs and background work with source/evidence links |
| `nouns-verbs.md` | Objects, actions and tried/untested sequences |
| `variables.md` | Variable families, variations and their evidence |
| `rules.md` | Named oracles, authority, scope and observations |
| `entities.md` | Attributes, relationships, CRUD and dependent outcomes |
| `states.md` | Lifecycle diagram and state/event should/predicted/observed table |
| `ecosystem.md` | Neighbours, trust boundaries, data paths and what-if results |
| `causes.md` | Findings grouped by cause and timestamped sibling predictions |

Mark inferred, observed, unknown and contradicted claims distinctly. Link observations to experiments and tag/build identity. A filled observed cell needs evidence; an inferred diagram arrow is not exercised coverage. Later experiments revise these files and explain the delta in `revealed.md`.
