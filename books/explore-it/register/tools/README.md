# Coordinator tools (excluded from blind exports)

Run from the repository root. These scripts were exercised for E01; they are coordinator helpers, not SUT instruments.

- `python3 books/explore-it/register/tools/prepare-export.py 2 explore-it/lesson-01`: archive only permitted trees into a new `/tmp/explore-it-experiment-02`, create the charter, sanitized export STATE.md and blind brief from the approved plan, and save metadata in `/tmp/explore-it-coordinator/current.json`. The destination must not already exist. The coordinator state is not exported: it contains answer-key material. Only the sanitized state generated with the charter enters the export. Each explorer uses its own Compose project, ports and image tag. The helper reads the answer-key plan and must never be given to a blind explorer.
- `bash books/explore-it/register/tools/run-explorer.sh`: fresh subscription-backed Opus 5.5 process, explicit local tool allowlist, 60-minute ceiling, JSONL output plus start/end/exit files. No API key or root environment bypass. Inspect launch errors before counting an experiment run.
- `python3 books/explore-it/register/tools/collect-record.py`: after the run closes, copy exploration artifacts unchanged, retain text evidence/helpers from ignored results, and save SHA-256 hashes and machine-readable execution evidence. The collector rejects modifications to inherited SUT source, raw reports and prior experiment records; defect-index updates must retain the complete inherited prefix. Sanitized export state is retained as run evidence. Audit tool paths independently; unchanged files alone do not prove blindness.

E01 showed why raw reports, canonical reconciled ids and fix status need separate records: 27 original reports describe several coupled planted faults and additional unplanned faults. Preserve the explorer's score and use register/reconciliations for the crosswalk. New runs use unique `E02-F01`-style identifiers to avoid overwriting inherited reports. Keep original raw reports immutable; update canonical D/U status records after fixes. Missing hooks and a failed probe are never evidence of defect absence.
